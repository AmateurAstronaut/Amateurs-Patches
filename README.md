A patch mod for KSP containing many different things I think are cool :)

Contents: 
BERD New Glenn Rebalance (Includes new plumes for all engines, block upgrades, resized BE4, BO Feather on a b9 switch and rebalanced tanks etc)
Sam's KNES plume patch (Applies the pretty KNES Vacuum plume to all cryogenic engines)
RL10 Variants patch (Adds 17 different historical and current variants of the RL10, interplay with BobKermanIndustries' RL10E-1 mod for an 18th variant)
